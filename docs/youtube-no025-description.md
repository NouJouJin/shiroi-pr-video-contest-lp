仕事と家事に追われる毎日の中で、母親はいつしか子どもの「もっと一緒にいたい」という小さなサインに気づけなくなっていた。

夜遅く帰宅した母親が見つけたのは、テーブルに残された夕飯と、子どもが描いた一枚の悲しそうな塗り絵。

その絵をきっかけに暮らし方を見つめ直し、白井市で新しい生活を始める家族の物語です。

公園で遊ぶ時間、梨園での体験、穏やかな街並み、家族で歩く夕暮れ。
白井市の自然や安心感、子育てしやすい環境の中で、失いかけていた家族の時間や、忙しさに埋もれていた家族との笑顔を少しずつ取り戻していきます。

---

制作では、物語性のあるPR動画にするため、絵コンテをもとに各カットの構図、人物配置、感情の流れを細かく設計しています。

人物が二人以上登場する場面や、家の構造・家具配置の整合性を保つことが難しく、各カットにつき5回以上プロンプトを調整。
カメラアングル、表情、手元、小道具、部屋の位置関係などを何度も修正し、約半月かけて完成させた、思い入れのある作品です。
