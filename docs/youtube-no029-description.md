親子三人で白井市に遊びに行った際に撮影した実写映像と、生成アニメを組み合わせた作品です。

前半では、白井市駅に到着した後、カラフルな住宅街に囲まれた「十余一公園」で散歩をしている様子を描いています。
住まいと自然が一体化しており、子育て世代に向けて「休日はゆったり過ごせる」というメッセージが込められています。

後半は、桜の名所である「今井の桜」でのお花見シーン。
ドローンによる空撮素材も活用し、都心から近く、住まいと自然が近い白井市の魅力を表現しています。

---

制作では、はじめてAI生成を利用した映像制作に挑戦。
学ぶところから始め、苦労しながらも、実写映像と生成アニメを組み合わせることで、白井市の心地よい距離感を表現しています。
