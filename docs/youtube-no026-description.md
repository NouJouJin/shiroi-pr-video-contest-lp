白井市のキャッチコピー「しろいはまっしろ はじまりのまち」から着想を得て制作された作品です。

コンセプトは「親目線で、子どもの未来を想像する」。

子どもの時に得る体験と感情は、成長に大きな影響を与えるもの。
本作品では、子どもが体験しているシーンを親が見守る構成を軸に、体を使った体験や、その中で生まれる笑顔が未来へつながっていく様子を描いています。

スマホひとつで多くの疑似体験ができる時代だからこそ、自分の体を使って感じる体験の大切さを表現。
子どもの笑顔が誰かを幸せにし、その連鎖が続いていく未来への思いが込められています。

---

制作では、カメラを「親の視点」として設計。
画像生成を丁寧に行い、動画生成ではKling 3.0 omniとSeedance 2.0を使い分けながら制作されています。

プロンプトはChatGPTと壁打ちしながら作成し、英語だけでなく日本語での指示も活用。
特に電車の走る向きの調整では、「手前から奥」ではなく「右から左」と指定するなど、生成結果を安定させる工夫が行われました。

女の子が梨を美味しそうに食べるシーンや、地図に画像をはめ込み動かすラスト表現など、印象的なカットにも挑戦しています。

TapNow（Kling 3.0 omni／Seedance 2.0）
